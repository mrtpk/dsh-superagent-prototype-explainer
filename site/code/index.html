Code map: the folder tree

Code mapabout 2 min read

Code version: dsh-superagent @ 6337fc8 · 2026-10-31

Purpose#

This page shows every folder of the repository. Click a folder name to open it at the pinned commit. Folders with a module page have a link to it.

The folder tree#

216 tracked files, 37,068 lines (text files only; counted with git ls-tree at the pinned commit).

  • docs/ 9 files · 1,973 lines The project's own numbered documentation, docs/000-philosophy.md through docs/008-cookbook.md.
  • examples/ 1 files · 12 lines A sample DSH profile patch file for installing the bundle.
  • locale/ 2 files · 12 lines
  • prompts/ 15 files · 438 lines Built-in prompt sections a team may override: admission, dispatch, work, handoff and team defaults.
    • prompts/team/ 3 files · 147 lines
  • scripts/ 1 files · 250 lines The dsh-superagent CLI: start, stop, restart and status, for use outside the agent itself.
  • skills/ 2 files · 26 lines The two bundled Source skills' instruction text, for the GitHub and Feishu Executor accounts.
    • skills/dsh-superagent-feishu/ 1 files · 12 lines
    • skills/dsh-superagent-github/ 1 files · 14 lines
  • src/ 111 files · 15,587 lines All production code: 92 .ts files, 18 .tsx files and one .css file.
    • src/app/ 38 files · 5,292 lines The glue: Runtime, Engine callers, Effects, Outbox, Sessions, Settings, Prompts, the management HTTP API and the views the panel reads.
    • src/client/ 27 files · 4,419 lines The React panel: the DeepSeek Harness sidebar plugin, its pages, and the bilingual copy and glossary.
    • src/core/ 15 files · 2,088 lines The domain core: Engine and its five parts (Intake, Evals, Tickets, Assignments, Replies), the Ticket stage machine, and the domain types. Imports no file outside this folder.
    • src/executor/ 2 files · 838 lines DshExecutor: one DSH Session and one directory per Ticket, worker slots, and background work.
    • src/infra/ 5 files · 347 lines Low-level glue: the CLI transport, the agent's process environment, package paths and the health board.
    • src/sources/ 16 files · 2,059 lines The GitHub and Feishu Source plugins: Triggers, Channels, polling and the Policy parts they own.
  • tests/ 65 files · 14,960 lines An unusually large test suite: 65 files, about 14,960 lines, nearly as large as production code.
    • tests/fixtures/ 6 files · 904 lines

How the numbers were measured#

The tool lists the tracked files with git ls-tree at the pinned commit. It counts the lines of text files. It does not count binary files.
